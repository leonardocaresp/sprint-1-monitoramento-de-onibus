
# DATABUS | Monitoramento da ocupação de ônibus


![Logo DataBus](https://raw.githubusercontent.com/leonardocaresp/sprint-1-monitoramento-de-onibus/d16e4bb88639f7162fa3cdddd40817332fe1d4a8/logo.svg)

O projeto engloba o uso de sensores de bloqueio/distância adquiridos por demanda do cliente – inclusive custeados e instalados nos veículos por esse - e codificados por nós, responsáveis pela criação do sistema. Será de nossa responsabilidade permitir que o usuário final tenha acesso a dados capturados por esses sensores em tempo real e de forma assíncrona, de forma que os dados relacionados à lotação dos ônibus e relatórios de desempenham alimentados por esses sejam salvos num banco de dados e que uma plataforma em site web permita sua visualização via dashboard acessível em múltiplos sistemas operacionais e navegadores de internet, sendo que o prazo para iniciação de operação é definido a depender das premências do cliente.
